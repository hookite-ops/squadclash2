# SQUAD CLASH 2 · 기계 침공

[SQUAD CLASH](https://github.com/hookite-ops/SquadClash)의 후속작. **노트북 브라우저용** 1인칭 슈팅 게임.

오리지널 무기고 19의 손·무기 동작(꺼내기·사격·재장전·볼트 조작·살펴보기)을 그대로 썼다.
격납고에 밀려오는 기계 부대(정찰 드론·크롤러·보행 전차)를 분대원 둘과 함께 웨이브마다 막고, 클리어할 때마다 보급 상자에서 무기 3개 중 하나를 골라 바꿔 든다. 5웨이브마다 보스.

## 조작 (키보드·마우스)

| 키 | 동작 |
|---|---|
| W A S D | 이동 |
| Shift | 달리기 |
| Space | 점프 |
| C | 앉기 (달리다 누르면 슬라이딩) |
| 좌클릭 / 우클릭 | 사격 / 정조준 |
| R | 재장전 |
| 1 · 2 · Q · 휠 | 무기 교체 |
| E | EMP (주변 기계 정지) |
| F | 무기 살펴보기 |
| Tab | 이번 판 기록 |
| Esc | 일시정지 · 설정 |

- 설정: 조작 기기(마우스 = 가속 없는 원시 입력 / 터치패드 = 조준 보조·자동 사격), 감도, 정조준 감도, Y축 반전, 정조준·앉기 방식(누르고 있기/전환), 시야각, 그래픽(자동/낮음/보통/높음), 효과음, 십자선 색
- 그래픽 '높음': 그림자 + 계단 현상 줄이기(MSAA 4x). '자동'은 높음에서 시작해 끊기면 한 단계씩 낮춤
- 휴대폰·태블릿 터치 조작도 그대로 들어 있음 (떠다니는 스틱·버튼 끌어 조준·조준 보조·자이로·배치 편집)

## 구성

- 무기 14종: 권총 3 · 기관단총 2 · 산탄총 2 · 소총 3 · 저격 2 · 기관총 2 (모델·애니메이션은 Blender 제작, meshopt 압축)
- three.js r170 (vendor 폴더에 포함), 빌드 과정 없음
- 음원: Kenney (CC0) + 짧은 합성 화약음
- nginx 정적 사이트(포트 8080) — Cloud Run 지속 배포
